Slipstream

Live TV that waits for you.

Slipstream records and plays live TV on your own server. Every screen answers one question first: how far behind live are you, and how do you get where you want to be? This page sets the visual rules and shows the key screens for TV, web and phone.

Direction

Calm screens, one bright signal

The look borrows from broadcast control rooms and timing screens: dark graphite surfaces, condensed numerals and very little colour. Colour carries meaning. When something is amber or red, it is the one thing you need to see.

Behind live, never lost

Wherever you can play something, show where you are relative to live: the delta and the timeline. Starting from the beginning is always one press away, and catching up is a choice.

Colour has a job

On TV, amber means focus, plus the playhead. On the web it marks the main action. Red means live or recording. Purple marks original quality. Artwork never uses those hues.

amber = you · red = now · purple = untouched

Ten feet first

The TV sets the scale: 22 px minimum text at 1080p, a 64 px safe margin, and a focus state you can see from the sofa. Web and phone are denser versions of the same system.

focus = amber fill + 4 px ring

Say what happened

No ffmpeg flags or jargon in normal views. Errors say what went wrong, when, what Slipstream already did, and what you can do. Technical detail sits behind Details.

"Missing 2 min (05:52–05:54). Source unreachable, reconnected."

Mark · final

Screen Ring

A television screen, cut on the product's 12° slant, its halves slipped past each other by one stroke width. The light half is the broadcast, which has moved on; the amber half is you, one beat behind. On launchers the mark turns ink on an amber tile. Full set (variants, sizes, adaptive icons, TV banner, lockups, motion, don'ts): docs/design/brand/brand-sheet.html.

Tokens

Colour, type, space, motion

These become packages/design-tokens: primitives, then semantic names, then component tokens. One JSON source generates Tailwind v4 CSS variables and a React Native theme. The package will precompute every tint per theme and surface, because React Native has no color-mix; this page still uses color-mix for brevity. Swatches follow this page's theme; the TV always uses the dark set.

Signature component

The timeline

One bar shows everything about a recording or live channel: what's captured, what you've watched, where you are, where live is, and what's still to come. The playhead is the same slash as in the mark, the only amber on the bar.

How it works

Grouping that isn't F1-only

Slipstream never knows what Formel 1 is, and grouping doesn't depend on how something was recorded. Rules decide what gets recorded; collections decide where it appears. Every recording gets a group path from the best structure available, in this order. The same path names exported files, so the library and the Plex folder always match.

1 · strongestCollections

A collection says which recordings belong together (channel and title words, e.g. titles starting with "F1:" or "Live F1:") and lays them out, e.g. Formel 1 › Year › Event › Programme. Parts come from text around separators (" - ", ": ", ",") or a selection in an example title. It applies to rule recordings, manual ones and imports alike.

2Series data from the guide

When the guide has season and episode numbers or an episode sub-title, recordings group as Show › Season › Episode, like Plex and Jellyfin.

3 · fallbackTitle and date

Everything else groups by its cleaned-up title (without "Live", "(Wh.)" and similar) and then by date. Films (guide category) go to Films › Title (Year).

helpersSuggestions and moving

When several recordings share a channel and title start, Slipstream suggests a collection. Moving a recording by hand asks "Also move similar ones in the future?" and extends the collection's match.

Components

Building blocks

Buttons, status chips, focus and the message pattern for problems.

Two focus styles on TV, both amber, no blur: controls get an amber fill plus a 4 px ring with a gap; picture cards keep their image and get the ring plus a 1.06 lift. Unfocused controls are neutral. Only transform and opacity animate.
